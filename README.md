Simple "Keep talking and nobody explodes" inspired mini game for 3 players. 
The game was developed for a DnD session where the players had to fix an engine of a boat. 
With some imagination the players are fixing the cables of the engine to make it start again. 

## Setup

Chose a seed in the main file and execute the main.py function. 
This will generate a maze_pin.png image. 

## How to play

The objective of the game is to connect 2 pins together based on a set of rules by navigating the maze without hitting any wall. 

### The guide 

Give one player the maze_pin.png image, this maps the layout of the maze and the position of the pins. They need to guide the fixer thought the maze.

### The fixer

Run the main.py file and give the computer the another player, they will have to navigate the maze and connect two pins. Left click on the two pins to connect them. 
Don't hit the walls or you lose

### The engineer

GGive the Manual.md to a player, based on the info of the fixer and guide they will tell which two pin to connect.
